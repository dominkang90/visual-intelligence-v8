# Gemini and Gemini CLI
## Gemini chat
Create a Gem or equivalent reusable instruction configuration if available for your account, using the concise global instructions as a starting point. This does not install a CLI skill.
## Gemini CLI
Use GEMINI.md for project guidance. Install the skill into a location supported by your Gemini CLI release if Agent Skills are enabled. Gemini CLI supports hooks in supported versions; confirm current event names, settings schema and security constraints in the official Gemini CLI documentation before adding executable commands. The hooks/*.md files here are non-executable quality checklists.
