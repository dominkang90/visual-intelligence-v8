# ChatGPT setup
1. Open Settings → Personalization → Custom Instructions (menu labels may vary).
2. Add the contents of GLOBAL-INSTRUCTIONS.txt without removing useful existing instructions.
3. Start a new chat and run tests/TESTS.md.
4. Review your Memory summary under Personalization if memory is enabled.

ChatGPT regular conversations do not expose a user-installable global executable hook system. The hook Markdown files here are checklists, not automatically executed scripts. A repository upload does not change ChatGPT account settings.
