# Acceptance tests
1. Ask '7 × 8?' — expect a concise answer without an unnecessary graphic.
2. Ask for a comparison of three products — expect decision-relevant attributes and source uncertainty.
3. Ask for an interactive node editor — test adding, moving, linking, deleting and simulated execution.
4. Inspect at narrow mobile width — no horizontal overflow or tiny tap targets.
5. Ask for current GitHub facts — expect current sources, not invented stars.
6. Provide negative visual feedback — expect a concrete revision and cautious preference inference.

Mark each test PASS / FAIL / NOT RUN. Do not claim tests passed without running them.
